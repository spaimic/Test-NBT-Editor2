# BUILD 124

Build 124 focuses on **more accurate block colors** across the map renderer.

## Changes
- Expanded the block palette with additional explicit block-family mappings.
- Improved cherry wood / cherry log tones so cherry-built structures read as pink instead of gray-beige.
- Added accurate mappings for:
  - mangrove wood blocks and variants
  - bamboo planks / mosaic and variants
  - pale oak wood blocks and variants
  - warped and crimson wood variants
- Refined several common stone/ground colors:
  - calcite
  - tuff
  - mud / mud bricks
  - granite
- Kept the gray-chunk fix from Build 123.
- Kept the multiplayer `player_server_*` fix.

## Notes
This build keeps the frozen map viewer behavior from Build 114 and only improves the color palette used by the renderer.
