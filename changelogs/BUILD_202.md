# Build 202

## Changes
- Removed the old Clipboard entry from the My Worlds overflow menu.
- Added a checkable **Always play the intro** option, ON by default.
- The intro preference now controls whether the Build 200 intro plays on app entry.
- Restored **Find Diamonds Near Player** and **Find Ancient Debris Near Player** to the small map-options FAB, using `search_diamond.png` and `search_ancient_debris.png`.
- Kept **Take Entire Map Picture** in the same FAB, using `camera.png`.
- When Experiment Mode is enabled, the intro adds a 3-second warning after the logo/title animation.
- The warning shows the requested warning text and supports a double-tap to skip immediately to My Worlds.
- The intro remains one-time only when the new preference is turned OFF; with the default ON setting it plays on every app entry.
